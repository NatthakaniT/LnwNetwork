# สรุปส่งต่อจากรอบที่ 1 (ภาค 0) ไปรอบที่ 2

สถานะ: รอบที่ 1 เสร็จบน branch `feat/round1` (ตัวแอป + ภาค 0 ครบ 5 บท พร้อมเสียง) ผ่านการตรวจรายงานแต่ละงานและตรวจรวมทั้ง branch แล้ว ไม่พบข้อมูล CCNA ผิด

## ต้องทำเป็นงานแรกของรอบที่ 2 ก่อนเขียนเนื้อหาภาค 1 (จากการตรวจรวม)

1. **ชี้กลับไปฉากที่ต้องดูใหม่ (spec ข้อ 11):** เพิ่ม `reviewScene?: string` ใน `QuizQuestion` + ตัวตรวจว่าเป็น scene id จริง + ปุ่ม "ดูฉากที่ N อีกครั้ง" เมื่อตอบผิด — ทำก่อนเขียนคำถามอีก ~280 ข้อ
2. **คำถามอังกฤษกดดูคำศัพท์ได้ทีละคำ (spec ข้อ 10):** ให้ prompt/choice ชั้น `en` ผ่าน RichText ร่วมกับไฮไลต์ keyword และเพิ่มกลุ่มศัพท์ "ภาษาข้อสอบ" (statement, purpose, responsible, most likely …)
3. **ตัวจำลองเครือข่ายรุ่น 2:** ส่งทีละ hop มีขั้นตอนให้ดู (ARP, frame/packet header, routing lookup, ทางกลับของ ping), static/default route, VLAN/trunk, ACL, ชุดคำสั่ง CLI ย่อย, ตรวจ IP ซ้ำเฉพาะที่เกี่ยวกับการส่งนั้น, goal แบบตรวจการตั้งค่า, กิจกรรมแบบคำนวณ/สุ่มโจทย์ (Subnetting), `exhibit` ในคำถาม (ผลลัพธ์ CLI), ทำ `ActivityLab` เป็น discriminated union
4. **ตัวกันพลาดทั้งคอร์ส:** test เดียวตรวจทุกบท ready (ความยาวบทพูด, ไม่มีตัวเลข/วงเล็บในบทพูด, ระยะห่าง actor, en มี keywords + textTh ทุกตัวเลือก, `correct` ไม่ว่าง, id ใน activity/lab มีจริง), manifest เสียงพร้อม hash ของบทพูด (กันเสียงเก่าค้าง), test ครอบ PRONOUNCE, RichText ใช้ศัพท์ทุกคำที่สอนมาแล้วถึงบทปัจจุบันอัตโนมัติ
5. **ตรึง lesson id** (ไม่ให้ขึ้นกับลำดับ) และ watchdog ในเครื่องเล่นฉากเมื่อเสียงค้าง
6. **คู่มือเขียนเนื้อหา:** ความหมายตายตัวของคำเปรียบเทียบ (กล่อง / ใบปะหน้า / รถ / ถนน / วง = หมู่บ้าน), ชื่อ server vs เครื่องเว็บ, เมื่อไหร่เปลี่ยนจาก "หมู่บ้าน" เป็น "วง/Subnet"; action "ล้างเวที" ระหว่างฉาก
