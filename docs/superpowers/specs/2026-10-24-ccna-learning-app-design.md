# แอปเรียน CCNA ภาษาไทยแบบเห็นภาพ — เอกสารออกแบบ

วันที่: 2026-10-24
สถานะ: ร่าง รอผู้ใช้อนุมัติ

## 1. ทำไมต้องมีแอปนี้

ผู้ใช้เป็นนักศึกษา ปวส. สาขาเครือข่ายคอมพิวเตอร์ (เทอม 2/2569) อยากสอบ CCNA 200-301 ของ Cisco จริง (ข้อสอบภาษาอังกฤษ) ภายในประมาณ 1 เดือน (ภายในราวปลายพฤศจิกายน 2026) เทอมที่แล้วเรียนวิชา 31908-2001 การสื่อสารข้อมูลและระบบเครือข่ายคอมพิวเตอร์ ซึ่งสอนตามคอร์ส Cisco NetAcad (ITN + SRWE และ ENSA บางส่วน) ได้คะแนนดี (กลางภาค 60/70, IP Address 18/20) แต่บอกเองว่า **"จำวิธีทำมาตอบ" ไม่ได้เข้าใจจริง** และรู้สึกว่า "งงพื้นฐานเลย ไม่เข้าใจอะไรเลย"

สาเหตุที่เห็นจาก Classroom: เนื้อหาหลักเป็นสไลด์ Cisco ภาษาอังกฤษทางการ และเอกสารสรุปสอนแบบ "พิมพ์คำสั่งนี้ → ได้ผลนี้" โดยไม่อธิบายว่าทำไม

สิ่งที่ได้ผลกับผู้ใช้ (รู้จากประสบการณ์จริง): ผู้ใช้เข้าใจ VLAN จากคลิป "Basic Network ตอนที่ 7" ของช่อง **9hua Training** เพราะ
- ใช้ภาษาที่เข้าใจง่าย
- เรียงสิ่งที่ต้องรู้ก่อน-หลังได้ดีมาก
- ยกตัวอย่างดีมาก เห็นภาพ
- มีทั้งช่วงอธิบายด้วยภาพ และช่วง LAB (ชอบช่วงภาพมากกว่า)

### ผู้เรียน

- ไม่ค่อยเข้าใจภาษาอังกฤษ
- ถ้าเจอภาษาทางการหรือคำกำกวมจะไม่เข้าใจ
- ต้องเข้าใจพื้นฐานของเรื่องนั้นก่อน แล้วค่อยขึ้นระดับสูง
- ต้องมีตัวอย่างในชีวิตจริงที่นึกภาพตามได้
- ชอบดูคลิป ชอบฟัง ชอบนึกภาพตาม
- เรียนโดยนั่งหน้าคอม (Windows 11, Chrome)

## 2. เป้าหมาย

1. ผู้ใช้ **เข้าใจจริง** ว่าทำไมเครือข่ายทำงานแบบนั้น อธิบายเป็นคำพูดตัวเองได้ ไม่ใช่จำสูตร
2. ครอบคลุมเนื้อหาสอบ CCNA ทั้งหมด (blueprint 200-301 ทั้ง 6 หมวด)
3. เริ่มเรียนได้เร็วที่สุด เพราะเวลาเหลือประมาณ 1 เดือน
4. ใช้ฟรีทั้งหมด

## 3. สิ่งที่ไม่ทำ (Non-goals)

- ไม่ทำแอปมือถือ ไม่ทำโปรแกรมติดตั้ง
- ไม่ช่วยงานหรือวิชาอื่นใน Google Classroom (CCNA เป็นหลักอย่างเดียว)
- ไม่แทนที่ Packet Tracer — ห้องทดลองในแอปเป็นแบบจำลองที่ง่ายกว่า เพื่อให้เห็นภาพ
- ไม่มีระบบสมาชิก ไม่มีหลายผู้ใช้
- ไม่ใช้บริการที่ต้องเสียเงิน

## 4. สิ่งที่ถ้าเกิดขึ้น = ล้มเหลว (Anti-goals)

ผู้ใช้บอกตรง ๆ ว่าจะเลิกใช้ถ้า:
- **ใช้ภาษาที่ไม่เข้าใจ**
- **เรียนแล้วไม่เข้าใจ**
- **ไม่ได้พัฒนาความรู้ไปจากเดิม**

ดังนั้นแอปที่ทำงานได้ทุกฟีเจอร์ แต่คำอธิบายเป็นภาษาทางการ แปลตรงตัวจากอังกฤษ หรือข้ามขั้น ถือว่าล้มเหลว

## 5. ข้อจำกัด

- ฟรีเท่านั้น ห้ามใช้ API หรือบริการเสียเงิน
- เครื่อง: Windows 11, Ryzen 7 7735HS, RAM 16 GB, RTX 3050 Laptop 4 GB, มี Node 22, Git, FFmpeg, uv
- เน็ตที่บ้านบล็อก huggingface.co ด้วย DNS (Chrome เปิดได้ด้วย secure DNS) — โหลดไฟล์โมเดลต้องโหลดผ่าน Chrome
- ห้ามคัดลอกสไลด์ Cisco หรือเนื้อหาที่มีลิขสิทธิ์มาใส่ — เขียนคำอธิบายใหม่เองทั้งหมด
- คลิป YouTube ใช้ด้วยการฝัง (embed) เท่านั้น ไม่ดาวน์โหลด (ตรวจแล้ว คลิป 9hua ตัวอย่าง `playableInEmbed: true`)
- ผู้ใช้ไม่เขียนโค้ด — ต้องเปิดใช้ได้ง่าย (ดับเบิลคลิกหรือคำสั่งเดียว)

## 6. สิ่งที่ผู้ใช้ตัดสินใจแล้ว

### 6.1 รูปแบบ: web app เปิดใน Chrome บนคอมผู้ใช้

### 6.2 บทเรียน 1 บท มี 4 ขั้น (ตามลำดับนี้)

1. **ดูคลิป 9hua ตอนที่ตรงกับบทนี้** (ฝังในหน้า) — ถ้า 9hua ไม่มีเรื่องนั้น ใช้คลิปไทยอื่น (Mr.Jodoi, KoChaiwat, [Basic/CCNA] ที่อาจารย์ใช้)
2. **ทบทวนด้วยภาพเคลื่อนไหวสั้น ๆ** (แบบ A ที่ผู้ใช้เลือก) — มีภาพขยับ เสียงพากย์ไทย คำบรรยายใต้ภาพ ปุ่มเล่น/หยุด/ย้อน/ขั้นต่อไป/ช้าลง เริ่มจากตัวอย่างในชีวิตจริงก่อน แล้วค่อยบอกว่าในโลก network คืออะไร และอธิบาย "ทำไม" เสมอ
3. **ลองเล่นในห้องทดลอง** (แบบ C ที่ผู้ใช้เลือก) — ลากอุปกรณ์ ต่อสาย ส่งข้อมูล เห็นข้อมูลวิ่ง ถ้าทำผิดบอกว่าผิดเพราะอะไรเป็นภาษาง่าย มีโจทย์ "อะไรเสีย ลองซ่อม"
4. **คำถามสั้น ๆ แนวข้อสอบ CCNA** — ผ่านแล้วบทถัดไปปลดล็อค

### 6.3 ครบทุกบท ปลดล็อคทีละขั้น

ผู้ใช้อนุมัติแผนที่บทเรียนนี้แล้ว (ประมาณ 45 บท):

**ภาค 0 · เริ่มจากศูนย์** (ไม่มีศัพท์ยาก ใช้ตัวอย่างชีวิตจริงล้วน)
1. Network คืออะไร (ถนนกับรถส่งของ)
2. อุปกรณ์มีอะไรบ้าง (คอม สาย Switch Router)
3. ข้อมูลเดินทางยังไง (กล่องพัสดุ)
4. ที่อยู่ 2 แบบ: MAC กับ IP (เลขบัตรประชาชน กับบ้านเลขที่)
5. การห่อของเป็นชั้น ๆ (OSI / TCP-IP)

**ภาค 1 · พื้นฐาน Network** (Network Fundamentals)
เลขฐานสอง · IPv4 · Subnet · ฝึก Subnetting · IPv6 · TCP กับ UDP · สายและรูปแบบการต่อ · Wi-Fi เบื้องต้น · Cloud และ Virtualization

**ภาค 2 · Switch และ VLAN** (Network Access)
Switch จำเครื่องได้ยังไง · VLAN · Trunk · คุยข้าม VLAN · STP · EtherChannel · CDP/LLDP · Wireless LAN

**ภาค 3 · Router และการหาเส้นทาง** (IP Connectivity)
Router เลือกทางยังไง · Static Route · Default Route · OSPF · FHRP

**ภาค 4 · บริการในเครือข่าย** (IP Services)
DHCP · DNS · NAT · NTP · SNMP/Syslog · QoS · SSH

**ภาค 5 · ความปลอดภัย** (Security Fundamentals)
ภัยที่พบบ่อย · รหัสผ่านและสิทธิ์ · ACL · Port Security · DHCP Snooping/DAI · VPN · ความปลอดภัย Wi-Fi

**ภาค 6 · ระบบอัตโนมัติ** (Automation and Programmability)
SDN และ Controller · REST API · JSON · Ansible/Terraform

แต่ละบทแสดงว่าตรงกับ Module ไหนของ NetAcad (ITN / SRWE / ENSA) เพราะผู้ใช้เคยเห็นสไลด์เหล่านี้ในห้อง

## 7. หลักการเขียนเนื้อหา (สำคัญที่สุด)

ทุกคำอธิบาย (บทพูด คำบรรยาย ข้อความในห้องทดลอง คำถาม) ต้องผ่านเช็คลิสต์นี้:

1. เริ่มจากตัวอย่างในชีวิตจริงที่คนไทยคุ้น (บ้านเลขที่ ไปรษณีย์ ถนน ห้างสรรพสินค้า หมู่บ้าน ฯลฯ) ก่อนพูดถึงศัพท์เทคนิค
2. ภาษาพูด ประโยคสั้น หนึ่งประโยคหนึ่งความคิด ห้ามภาษาทางการ ห้ามแปลตรงตัวจากอังกฤษ
3. ศัพท์อังกฤษใช้เฉพาะคำที่ต้องเจอในข้อสอบ ทุกคำมีคำอธิบายไทยติดอยู่ (เช่น ชี้แล้วเห็นคำอธิบาย) และอธิบายครั้งแรกที่เจอเสมอ
4. บอก "ทำไม" ทุกครั้ง ไม่ใช่แค่ "ทำอะไร" — ทุกคำสั่ง Cisco ต้องตอบได้ว่า ถ้าไม่พิมพ์คำสั่งนี้จะเกิดอะไร
5. ห้ามใช้ความรู้ที่ยังไม่ได้สอนในบทก่อนหน้า (เรียงก่อน-หลังแบบ 9hua)
6. ผู้ใช้ได้คะแนนดีจากการจำวิธีทำ — คำถามท้ายบทต้องวัดความเข้าใจ (ถามว่าทำไม / อะไรเสีย / เกิดอะไรถ้า...) ไม่ใช่ถามให้จำคำสั่ง

## 8. ห้องทดลอง (Sandbox)

- จำลองอุปกรณ์: PC, Laptop, Switch, Router, Access Point, Server (เพิ่มตามบท)
- เห็นกล่องข้อมูล (packet) วิ่งไปตามสายเป็นภาพเคลื่อนไหว
- แต่ละบทมีโจทย์ของตัวเอง (เป้าหมาย + ตัวช่วย) และบางบทมีโจทย์ "มีของเสีย หาให้เจอ"
- โจทย์สำคัญควรต่อยอดจากของที่ผู้ใช้เคยทำในห้อง เช่น สถานการณ์ "Network Plus" HQ กับ Branch (IP, DHCP, WLAN, Static/Default Route) และงานเทอมนี้ "ทำไมเครื่องลูก ping 8.8.8.8 ไม่ได้"
- ภาค 0 ไม่มีการพิมพ์คำสั่ง ภาคหลัง ๆ มีการพิมพ์คำสั่ง Cisco ชุดย่อยที่เกี่ยวกับบทนั้น พร้อมคำอธิบายไทยทุกคำสั่ง

## 9. ความคืบหน้า

- จำว่าจบบทไหนแล้ว บทไหนกำลังเรียน บทไหนยังล็อค
- แสดงแถบความคืบหน้ารวม (ตามภาพตัวอย่างแผนที่บทเรียนที่ผู้ใช้เห็นแล้ว)

## 10. ข้อสอบจริงเป็นภาษาอังกฤษ (ผู้ใช้ยืนยันแล้ว)

ผู้ใช้จะสอบ **CCNA 200-301 ของ Cisco จริง** (Pearson VUE) ซึ่งข้อสอบเป็นภาษาอังกฤษทั้งหมด ดังนั้น:

- **เนื้อหาสอนยังเป็นภาษาไทยง่าย ๆ** ตามหลักการข้อ 7 (ไม่เปลี่ยน)
- **คำถามท้ายบทมี 2 ชั้น:** ชั้นแรกถามเป็นภาษาไทยเพื่อวัดความเข้าใจ ชั้นที่สองเป็นคำถามภาษาอังกฤษแบบข้อสอบจริง โดยมีตัวช่วย — กดดูคำแปลไทยทั้งข้อได้ ชี้คำศัพท์ทีละคำได้ และไฮไลต์ "คำสำคัญที่บอกว่าโจทย์ถามอะไร" (เช่น *NOT*, *best*, *two answers*)
- **คลังคำศัพท์ข้อสอบ:** ทุกศัพท์อังกฤษที่เจอในบท เก็บเข้าคลัง มีคำอธิบายไทยแบบเห็นภาพ ทบทวนได้
- ในบทแรก ๆ เน้นคำถามไทย แล้วค่อย ๆ เพิ่มสัดส่วนคำถามอังกฤษตามภาคที่สูงขึ้น (การตัดสินใจของผู้เขียนเอกสาร)

## 11. ลำดับการสร้าง

ผู้ใช้เลือก: **ทุกบทต้องครบ 4 ขั้น (คลิป → ภาพเคลื่อนไหว → ห้องทดลอง → คำถาม) ถ้าทำไม่ทัน ให้ทำหัวข้อที่ออกสอบเยอะก่อน** ไม่ทำบทแบบลดขั้น

รายละเอียดต่อไปนี้เป็นการตัดสินใจของผู้เขียนเอกสาร:
1. **รอบแรก:** ตัวแอป (แผนที่บทเรียน, หน้าบทเรียน 4 ขั้น, เครื่องเล่นภาพเคลื่อนไหว, ห้องทดลองพื้นฐาน, ระบบคำถาม 2 ชั้น, คลังศัพท์, ความคืบหน้า) + ภาค 0 ครบ 5 บท — ภาค 0 ต้องมาก่อนเสมอเพราะเป็นฐานของทุกอย่าง
2. **ลำดับหลังจากนั้นตามน้ำหนักข้อสอบ** (blueprint 200-301: IP Connectivity 25%, Network Fundamentals 20%, Network Access 20%, Security 15%, IP Services 10%, Automation 10%) และหัวข้อที่ออกบ่อย:
   IPv4 + Subnet + Subnetting → Switch/VLAN/Trunk/Inter-VLAN → Routing (Static, Default, OSPF) → DHCP/DNS/NAT → ACL/Port Security/รหัสผ่าน → STP/EtherChannel → IPv6 → Wireless LAN → TCP/UDP, สาย → ที่เหลือ
3. **บทที่ยังไม่ได้สร้าง:** แสดงบนแผนที่ว่า "กำลังทำ" และไม่ขวางการปลดล็อค บทถัดไปที่สร้างแล้ว (ถ้าบทที่สร้างแล้วต้องใช้ความรู้จากบทที่ยังไม่สร้าง ให้ใส่สรุปสั้น ๆ ของเรื่องนั้นไว้ในบท)
4. **ทุกบทที่เสร็จ** ให้ผู้ใช้ลองเรียนจริงแล้วบอกว่าเข้าใจไหม — ถ้าไม่เข้าใจ แก้ภาษา/ตัวอย่างก่อนทำบทถัดไป

### การตัดสินใจเพิ่มเติมของผู้เขียนเอกสาร (ห้องทดลอง คำถาม และไฟล์เสียง — ผู้ใช้ตรวจได้)

- **ห้องทดลองไม่จำเป็นต้องเป็นแบบลากอุปกรณ์ทุกบท** บทที่ไม่เกี่ยวกับการต่อเครือข่าย (เช่น JSON, REST API, Ansible, Cloud, ภัยคุกคาม) ใช้กิจกรรมลงมือแบบอื่นแทน เช่น ลากเรียงขั้นตอน จับคู่ แก้ไฟล์ JSON แล้วเห็นผล ห้องทดลองจำลองเครือข่ายรองรับเฉพาะสิ่งที่บทนั้นต้องใช้ ไม่สร้างตัวจำลองครบทุกโปรโตคอลตั้งแต่แรก
- **คำถามท้ายบท:** ผ่านที่ 80% ทำซ้ำได้ไม่จำกัด ถ้าตอบผิด อธิบายว่าทำไมผิดเป็นภาษาง่าย แล้วชี้กลับไปส่วนที่ต้องดูใหม่
- **ข้ามบทได้ด้วย "สอบข้ามบท":** บทที่ยังล็อค ถ้าทำคำถามของบทนั้นผ่านเลย ก็ปลดล็อคได้ทันที (เพราะผู้ใช้เคยเรียน ITN/SRWE มาแล้ว และเวลามีน้อย) ลำดับปกติยังเป็นทีละบท
- **ไฟล์เสียง:** ย้ายสคริปต์และไฟล์โมเดลมาไว้ในโปรเจกต์แล้วที่ `tools/tts/` (`gen_local.py`, `models/` 4 ไฟล์ ตรวจ SHA-256 ตรงกับต้นฉบับ, `ref/ref_gen_4.wav`) — Python env ยังอยู่ใน scratchpad ต้องสร้างใหม่ในโปรเจกต์ (uv + Python 3.10 + torch 2.3.0+cu118 + f5-tts-th) และห้ามเก็บ `models/` ใน git
