# ปรับหน้าตาเว็บใหม่ (ธีมมืด + motion) — เอกสารออกแบบ

วันที่: 2026-10-25
สถานะ: ร่าง รอผู้ใช้อนุมัติ
ต่อจาก: `2026-10-24-ccna-learning-app-design.md` (กฎเนื้อหาและภาษาทั้งหมดยังใช้เหมือนเดิม)

## 1. ทำไม

ผู้ใช้บอกว่า "ทุกหน้าดูแข็ง ๆ" อยากให้มี animation และ motion ที่ "สวยงามพอดี" เว็บอ้างอิงที่ผู้ใช้ชอบ:
- dovvstudio.com — ตัวหัวข้อหนาใหญ่, การ์ดสีสดเอียงนิด ๆ, สติกเกอร์ลอย, ของค่อย ๆ ขยับเข้ามา
- chalakorn-portfolio.noicely.win — พื้นมืด สีเด่นสีเดียว, ตัวหนาใหญ่, แถบตัวหนังสือเลื่อน

## 2. สิ่งที่ผู้ใช้เลือกแล้ว (ดู mockup ใน .superpowers/brainstorm/1097-1792819585/content/b-dark.html)

- **แบบ B (การ์ดหลายสีแบบ DOVV) แต่เป็นธีมมืด** — พื้นเกือบดำ `#0e0f13`, การ์ดแต่ละภาคสีสดและเอียงเล็กน้อย, ชี้แล้วเด้งขึ้น, ภาคที่ยังไม่ถึงสีจาง + ป้าย "🔒 ยังไม่ถึง", บทปัจจุบันเป็นแถบเด่นในการ์ด, ตัวหัวข้อลอยขึ้นตอนเปิดหน้า, แถบความคืบหน้าวิ่ง, สติกเกอร์ลอยมุมขวา
- **ปรับทุกหน้า** ไม่ใช่แค่หน้าแรก
- **หน้าคลังศัพท์:** แยกส่วน **OSI Model** ออกมาเป็นของตัวเอง — แถบ 7 ชั้นสีต่างกัน (7 บนสุด → 1 ล่างสุด) แต่ละชั้นมีคำสั้นผูกกับเรื่องที่เรียน (เช่น 3 = ใบปะหน้า · IP), กรอบ TCP/IP 4 ชั้นวางเทียบข้าง ๆ ให้ตรงชั้น, กดชั้นแล้วเห็นคำอธิบายเต็ม; ศัพท์ OSI อื่น ๆ และศัพท์ทั่วไปแยกกลุ่ม
- **ศัพท์ทุกคำต้องเห็นคำอธิบายเลย** (ไม่ใช่แค่ชื่อเป็นเม็ด ๆ) — การ์ดแต่ละคำแสดง `en`, `th`, `explainTh`
- **เนื้อหาศัพท์อยู่ครบ** 39 คำเดิม ไม่ลด ไม่แก้ถ้อยคำ

## 3. ระบบหน้าตา (การตัดสินใจของผู้เขียนเอกสาร ตามแนวทาง frontend-design + กฎ ui-ux-pro-max)

**สี (ตัวแปร CSS บน :root เท่านั้น ไม่ใส่ hex ใน component)**
- พื้น `--bg #0e0f13`, ผิวการ์ด `--surface #181a21`, เส้น `--border #2a2d38`, ตัวหนังสือ `--text #f1f1ee`, รอง `--text-muted #a3a6b0`
- สีประจำภาค: ภาค 0 `#c8f169` (เขียวมะนาว), 1 `#ff7ad9` (ชมพู), 2 `#4c7dff` (น้ำเงิน), 3 `#ff5a1f` (ส้ม), 4 `#ffd23f` (เหลือง), 5 `#4cd4ff` (ฟ้า), 6 `#b58cff` (ม่วง) — ใช้ซ้ำในหน้าบทเรียนเป็นสีเน้นของบทนั้น
- สีความหมาย: ถูก `#3fb950`, ผิด `#f85149`, กำลังทำ = สีภาค
- ตัวหนังสือบนการ์ดสีต้องผ่าน contrast ≥ 4.5:1 (ตัวดำบนสีสว่าง, ตัวขาวบนน้ำเงิน/ส้ม/ม่วง)

**ฟอนต์**
- หัวข้อ: Kanit 800/900 (ผ่าน `@fontsource/kanit` ให้ใช้ได้แบบไม่มีเน็ต)
- เนื้อหา: Noto Sans Thai 400/700 เหมือนเดิม ขนาดพื้นฐาน 18px, line-height 1.7

**motion (หลักการ)**
- ใช้ CSS ล้วน + hook เล็ก ๆ สำหรับ scroll-reveal (IntersectionObserver) — ไม่เพิ่มไลบรารี animation
- เปิดหน้า: หัวข้อ/ส่วนต่าง ๆ ลอยขึ้นทีละชั้น (stagger ~80-120ms, 500-700ms, easing ออกนุ่ม)
- ชี้/กด: การ์ดเด้งขึ้นเล็กน้อย, ปุ่มยุบตอนกด, แท็บขั้นตอนเลื่อนแถบใต้แท็บไปตำแหน่งใหม่
- ตอบถูก/ผ่านเป้าหมาย: เด้งฉลองสั้น ๆ (≤600ms) — motion ที่ตอบสนองการกระทำของผู้ใช้
- **ห้าม:** motion ระหว่างที่ภาพเคลื่อนไหวบทเรียนกำลังเล่น (ไม่แย่งความสนใจจากเนื้อหา), อะไรที่วนไม่หยุดในหน้าบทเรียน (สติกเกอร์ลอยมีได้เฉพาะหน้าแผนที่)
- **ต้องเคารพ `prefers-reduced-motion`:** ปิดทุก animation ที่ไม่จำเป็น เหลือแค่การเปลี่ยนสถานะทันที

## 4. หน้าที่ต้องปรับ

1. **แผนที่บทเรียน (CourseMap):** ตาม mockup B ธีมมืด — การ์ดภาคแบบกริด 4 คอลัมน์ (จอ ≥1280), รายชื่อบทในการ์ด, ปุ่ม "สอบข้ามบท" และ "เรียนต่อ" ยังอยู่, ข้อความ "เรียนแล้ว N จาก M บท", ประกาศ (notice) เป็นการ์ดลอยที่ปิดได้ — สติกเกอร์ใช้ข้อความให้กำลังใจที่ไม่อ้างวันสอบ (ยังไม่รู้วันสอบจริง)
2. **หน้าบทเรียน (LessonPage):** หัวบทใหญ่แบบ Kanit พร้อมสีของภาค, ป้าย "ตรงกับ Cisco", แท็บ 4 ขั้นเป็นปุ่มแคปซูล + แถบเลื่อนบอกขั้นปัจจุบัน, เนื้อหาแต่ละขั้นลอยเข้าตอนเปลี่ยนขั้น, ปุ่ม "ไปขั้นต่อไป" เด่นด้วยสีภาค
3. **ขั้นคลิป (VideoStep):** กรอบวิดีโอโค้งมนพร้อมเงา, หมายเหตุ noteTh เป็นการ์ดสีเหลืองอ่อนแบบสติกเกอร์
4. **ขั้นภาพทบทวน (ScenePlayer):** เปลี่ยนแค่กรอบ, ปุ่มควบคุม, คำบรรยาย — **ไม่แตะ** ไอคอนและภาพเคลื่อนไหวในเวที
5. **ห้องทดลอง/กิจกรรม (LabView, ActivityView):** การ์ดเป้าหมายเด่น, ผลการส่งเป็นการ์ดสีถูก/ผิดที่เด้งเข้า, ปุ่ม ⬆⬇ ลื่นขึ้นด้วยการเลื่อนตำแหน่งแบบ animate
6. **คำถาม (QuizView):** ตัวเลือกเป็นการ์ด, ตอบแล้วการ์ดถูกเรืองเขียว/ผิดสั่นเบา ๆ, หน้าคะแนนเด้งฉลองเมื่อผ่าน
7. **คลังศัพท์ (GlossaryPage):** ตามข้อ 2 — ส่วน OSI + กลุ่มศัพท์ที่ทุกคำมีคำอธิบาย, ช่องค้นหายังใช้ได้ทั้งไทย/อังกฤษ และค้นแล้วต้องเจอศัพท์ OSI ด้วย
8. **ป๊อปอัปศัพท์ (Term), แจ้งเตือน, ErrorBoundary:** ใช้ระบบสีและมุมโค้งเดียวกัน

## 5. สิ่งที่ไม่ทำ / ห้ามเกิด

- ไม่เปลี่ยนเนื้อหาบทเรียน ถ้อยคำ เสียง หรือภาพเคลื่อนไหวในเวที
- ไม่เปลี่ยนพฤติกรรม (ปลดล็อค ให้คะแนน ห้องทดลอง) — test เดิมทั้งหมดต้องผ่าน
- ไม่ทำให้อ่านยากขึ้น: ตัวหนังสือเนื้อหายัง ≥18px, contrast ผ่าน, ตัวหนาใหญ่ใช้กับหัวข้อเท่านั้น
- ไม่รองรับมือถือเพิ่ม (ยังเน้นจอคอม ≥1280px) แต่ห้ามมี scroll แนวนอนที่ 1280

## 6. การตัดสินใจของผู้เขียนเอกสาร (จากคำถามของผู้ตรวจ — ผู้ใช้ตรวจได้)

1. **test:** test ที่ตรวจพฤติกรรม (ปลดล็อค ให้คะแนน ห้องทดลอง ลำดับขั้น ค้นศัพท์) ต้องผ่านเหมือนเดิม; test ที่ผูกกับ CSS เดิม (`styles.test.ts`) หรือโครง DOM/ข้อความหน้าตาแก้ให้ตรงของใหม่ได้ แต่ต้องยังตรวจเรื่องเดิม (ปุ่ม disabled ดูออกว่ากดไม่ได้, ข้อความ pre-line, ตัวเลือกคำถามที่ตอบแล้วไม่จาง)
2. **คำสั้นของแต่ละชั้น OSI:** เก็บในไฟล์ข้อมูลใหม่ `src/content/osi.ts` (ไม่แก้ `GlossaryTerm`) ใช้คำเปรียบเทียบเดียวกับบท p0-l5: 7 ชั้นที่โปรแกรมใช้คุย · 6 จัดรูปแบบ เข้ารหัส · 5 เปิด-ปิดการคุย · 4 กล่อง · port · 3 ใบปะหน้า · IP · 2 รถ · MAC · 1 ถนน · สัญญาณ; ผูกแต่ละชั้นกับ glossary id ของชั้นนั้น และผูก TCP/IP 4 ชั้นกับ id ของมัน
3. **กดชั้นแล้วแสดง:** `en`, `th`, `explainTh` เดิมของศัพท์ชั้นนั้น (ไม่เขียนข้อความใหม่) — ศัพท์ 7 ชั้น + Internet layer + Network Access layer อยู่ในส่วน OSI เท่านั้น ไม่ซ้ำในกลุ่มอื่น; ช่องค้นหายังเจอทุกคำ รวม 39 คำครบ (มี test นับ)
4. **แผนที่ 7 ภาค:** กริด 4 คอลัมน์ ห่อเป็น 4 + 3; มุมเอียงวนตามลำดับภาค (−2°, 1.5°, −1°, 2°); ตัวหนังสือดำบนภาค 0,1,4,5 และขาวบนภาค 2,3,6 — ตรวจ contrast ทุกคู่ด้วยการคำนวณใน test; การ์ดที่ยังไม่ถึงทำให้ "จาง" ด้วยการลดความสดของพื้นการ์ดเท่านั้น ตัวหนังสือในการ์ดยังต้องผ่าน contrast
5. **"ยังไม่ถึง":** ตรรกะปลดล็อคยังเป็นรายบทเหมือนเดิม; การ์ดภาคแสดงป้าย "🔒 ยังไม่ถึง" เมื่อไม่มีบทไหนในภาคนั้นเปิดได้; รายชื่อบทยังแสดงในการ์ดทุกใบ; ปุ่ม "สอบข้ามบท" ยังอยู่ที่บทที่ ready แต่ล็อค
6. **ฟอนต์:** เพิ่ม `@fontsource/kanit` น้ำหนัก 500, 800, 900 (ใช้แบบไม่ต้องมีเน็ต)
7. **สติกเกอร์:** ข้อความให้กำลังใจชุดเล็กที่ตายตัว เลือกตามความคืบหน้า (เช่น 0 บท "เริ่มกันเลย 💪", ระหว่างทาง "สู้ ๆ ทีละบท 🔥", จบภาคไหน "เก่งมาก ผ่านภาค N แล้ว 🎉") ไม่สุ่ม ไม่อ้างวันสอบ
8. **ประกาศ (notice):** อยู่บนหน้าแผนที่เท่านั้น พฤติกรรมปิดเหมือนเดิม (ไม่ต้องจำข้ามการรีเฟรช)
9. **"ห้าม motion ระหว่างภาพเคลื่อนไหวเล่น":** หมายถึงห้ามมีของตกแต่งที่ขยับหรือวนใกล้/ในกรอบเวที และห้ามสิ่งที่วนไม่หยุดในหน้าบทเรียน — ไม่ต้องหยุด transition ของปุ่มหรือแท็บระหว่างเล่น (ไม่ต้องส่งสถานะเล่นขึ้นไปที่ LessonPage)
10. **เวทีภาพเคลื่อนไหว:** เปลี่ยนสีพื้นเวทีและกรอบให้เข้ากับธีม (ผ่านตัวแปรสี) ได้ แต่ไม่แตะไอคอน ป้าย และ animation ของ actor; ต้องเช็คว่าไอคอนและป้ายยังอ่านชัดบนพื้นใหม่
11. **กรอบ YouTube:** เพิ่มแค่มุมโค้ง ขอบ และเงา

## 7. ปล่อยให้ผู้สร้างตัดสินใจ

- รายละเอียดเวลา/easing ของแต่ละ animation ภายใต้หลักข้อ 3
- โครงไฟล์ CSS (แนะนำ: ไฟล์ token กลาง + CSS ประจำ component)
- จะจัดกลุ่ม "ศัพท์ทั่วไป" ตามภาคเหมือนเดิมหรือรวมเป็นกลุ่มเดียว (แนะนำ: ตามภาค เพราะช่วยให้รู้ว่าศัพท์มาจากบทไหน)
- ลำดับส่วน OSI กับส่วนอื่นในหน้าคลังศัพท์ (mockup วาง OSI ไว้บนสุด)
