# ตั้งครูถามตอบใน Claude.ai ทีละขั้น

ครูคือ Project ใน Claude.ai (ฟรี ไม่มี AI ในแอป) ทำครั้งเดียวแล้วใช้ต่อได้เลย

## ตั้งครั้งแรก

1. เปิด https://claude.ai แล้วเข้าสู่ระบบ
2. เมนูซ้าย กด **Projects** แล้วกด **Create project** (สร้างโปรเจกต์)
3. ตั้งชื่อ เช่น "ครู CCNA" ใส่คำอธิบายสั้น ๆ แล้วกดสร้าง
4. เปิดไฟล์ `docs/tutor/instructions.md` คัดลอกข้อความทั้งหมด
5. ในหน้า Project กดปุ่ม **Set project instructions** (ตั้งคำสั่งโปรเจกต์) วางข้อความ แล้วกด **Save**
6. ในช่อง **Files** (ไฟล์ความรู้) กด **+** แล้วอัปโหลด `docs/tutor/roadmap.md`
7. เริ่มแชตใหม่ใน Project นี้ ลองถาม "สวัสดี ผมเพิ่งเริ่มเรียน" ครูควรตอบเป็นไทยเป็นกันเอง

## ใช้งานตอนเรียน

1. ในแอป ตอนติดตรงไหน กดปุ่ม **📋 คัดลอกไปถามครู** (อยู่ท้ายหน้าบทเรียน)
2. แอปคัดลอกข้อความให้ในรูปแบบ `ผมเรียนถึงบท "<ชื่อบท>" ขั้น "<ชื่อขั้น>" [ตอบข้อ "<คำถาม>" ผิด] อยากถามว่า ` ถ้าตอบข้อไหนผิด จะมีชื่อข้อนั้นติดมาด้วย
3. ไปที่แชตของ Project แล้วกดวาง (Ctrl+V)
4. พิมพ์คำถามต่อท้ายคำว่า "อยากถามว่า" แล้วกดส่ง
5. ครูใช้ชื่อบทไปหาตำแหน่งใน `roadmap.md` จึงรู้ว่าคุณเรียนถึงไหนและไม่พูดเรื่องที่ยังไม่ถึง
6. ถ้ากดปุ่มแล้วแอปบอกให้เลือกข้อความคัดลอกเอง ให้ลากเลือกข้อความที่แสดง แล้วกด Ctrl+C

## ทุกครั้งที่มีบทใหม่

`roadmap.md` สร้างจากข้อมูลคอร์สในแอป ห้ามแก้มือ ทุกครั้งที่เพิ่มบทหรือบทเปลี่ยนจาก "กำลังทำ" เป็น "พร้อมเรียน":

1. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน `npm run roadmap:export`
2. ใน Project บน Claude.ai ลบ `roadmap.md` เก่าออกจาก Files แล้วอัปโหลดไฟล์ใหม่ที่ `docs/tutor/roadmap.md`
