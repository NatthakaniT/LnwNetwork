# แผนที่คอร์ส LnwNetwork (สร้างจากสคริปต์ ห้ามแก้มือ)

เรียงตามลำดับที่ผู้เรียนเรียน ผู้เรียนรู้เฉพาะเรื่องในบทก่อนหน้าบทที่เรียนอยู่เท่านั้น

## ภาค 0 · เริ่มจากศูนย์

- Network คืออะไร (ถนนกับรถส่งของ) — พร้อมเรียน
- อุปกรณ์มีอะไรบ้าง (คอม สาย Switch Router = บ้าน ถนน ไปรษณีย์ในหมู่บ้าน ไปรษณีย์กลาง) — พร้อมเรียน
- ข้อมูลเดินทางยังไง (กล่องพัสดุ) — พร้อมเรียน
- คอมพูดภาษา 0 กับ 1 (สวิตช์ไฟกับทอนเงินด้วยแบงก์) — พร้อมเรียน
  - ต่อจาก: ข้อมูลเดินทางยังไง · ข้อมูลที่วิ่งในสายคือสิ่งที่เราจะดูว่าคอมเก็บยังไง
- ที่อยู่ 2 แบบ: MAC กับ IP (เลขบัตรประชาชน กับบ้านเลขที่) — พร้อมเรียน
  - ต่อจาก: คอมพูดภาษา 0 กับ 1 · เลข 0 ถึง 255 ของแต่ละก้อนมาจาก 1 byte
- การห่อของเป็นชั้น ๆ (ห่อพัสดุทีละชั้น) — พร้อมเรียน
