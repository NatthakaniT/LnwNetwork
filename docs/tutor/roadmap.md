# แผนที่คอร์ส LnwNetwork (สร้างจากสคริปต์ ห้ามแก้มือ)

เรียงตามลำดับที่ผู้เรียนเรียน ผู้เรียนรู้เรื่องในบทก่อนหน้าทั้งหมด รวมบทที่เรียนอยู่ตอนนี้ แต่ยังไม่รู้เรื่องในบทที่อยู่หลังบทนั้น

"สอน:" คือศัพท์ที่บทนั้นสอนเป็นครั้งแรก / "ต่อจาก:" คือบทก่อนหน้าที่บทนั้นต้องใช้ความรู้

## ภาค 0 · เริ่มจากศูนย์

- Network คืออะไร (ถนนกับรถส่งของ) — พร้อมเรียน
  - สอน: Network, Data, LAN, WAN, Internet
- อุปกรณ์มีอะไรบ้าง (คอม สาย Switch Router = บ้าน ถนน ไปรษณีย์ในหมู่บ้าน ไปรษณีย์กลาง) — พร้อมเรียน
  - สอน: End device, Cable, Switch, Router, Gateway, IP address
  - ต่อจาก: Network คืออะไร · network คือเครื่องที่ต่อถึงกันจนส่งข้อมูลหากันได้ บทนี้ดูว่าต่อกันด้วยอุปกรณ์อะไรบ้าง
- ข้อมูลเดินทางยังไง (กล่องพัสดุ) — พร้อมเรียน
  - สอน: Packet, Source, Destination, DNS, Domain name
  - ต่อจาก: อุปกรณ์มีอะไรบ้าง · Switch ส่งของในหมู่บ้าน Router ส่งของข้ามหมู่บ้าน บทนี้ดูว่าข้อมูลวิ่งผ่านสองตัวนี้ยังไง
- คอมพูดภาษา 0 กับ 1 (สวิตช์ไฟกับทอนเงินด้วยแบงก์) — พร้อมเรียน
  - สอน: Bit, Byte, Binary, Bits, IPv4
  - ต่อจาก: ข้อมูลเดินทางยังไง · ข้อมูลที่วิ่งในสายคือสิ่งที่เราจะดูว่าคอมเก็บยังไง
- ที่อยู่ 2 แบบ: MAC กับ IP (เลขบัตรประชาชน กับบ้านเลขที่) — พร้อมเรียน
  - สอน: MAC address, ARP, NIC
  - ต่อจาก: คอมพูดภาษา 0 กับ 1 · IP ตัดเป็น 4 ก้อน แต่ละก้อนคือ 1 byte เลยเป็นเลข 0 ถึง 255
- การห่อของเป็นชั้น ๆ (ห่อพัสดุทีละชั้น) — พร้อมเรียน
  - สอน: Layer, OSI model, TCP/IP model, Encapsulation, De-encapsulation, PDU, Segment, Frame, Port, Application layer, Presentation layer, Session layer, Transport layer, Network layer, Internet layer, Data Link layer, Physical layer, Network Access layer
  - ต่อจาก: ที่อยู่ 2 แบบ: MAC กับ IP · ใบปะหน้าแต่ละชั้น เขียนที่อยู่ IP กับ MAC ที่รู้จักแล้ว
  - ต่อจาก: คอมพูดภาษา 0 กับ 1 · ชั้นนอกสุด ส่งออกไปเป็น bit คือ 0 กับ 1 ทีละตัว
